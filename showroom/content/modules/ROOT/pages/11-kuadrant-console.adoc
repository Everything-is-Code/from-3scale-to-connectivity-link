= Kuadrant Console (Connectivity Link plugin)

Day-2 operations for Connectivity Link happen in the *Kuadrant Console* — an OpenShift Console dynamic plugin (`custom-rhcl-console`) that surfaces API Products, API Keys, traffic metrics, Grafana deep links, and Swagger UI.

== Architecture

image::kuadrant-console-arch.png["Kuadrant Console architecture — OpenShift Console plugin, Kuadrant CRDs, Grafana and Tempo"]

The plugin talks to the cluster through the Console API proxy (`consoleFetch`). It manages Kuadrant CRDs such as `APIProduct`, `APIKey`, `AuthPolicy`, `RateLimitPolicy`, and `PlanPolicy`, and deep-links into Grafana RHCL dashboards and Tempo traces.

== Where to open it

. Log in to the *OpenShift Console* (workshop platform user or cluster-admin).
. In the left navigation, open *Connectivity Link* (plugin display name).
. Explore:
** *API Products* — inventory of products in `kuadrant-console-demo` and other namespaces
** *API Keys* — create, approve/reject, reveal key material from Secrets
** *Traffic / cost* — overview metrics backed by Thanos / Prometheus

TIP: If the plugin menu is missing, confirm the `ConsolePlugin` `custom-rhcl-console` is enabled and the plugin Deployment in namespace `custom-rhcl-console` is Ready.

== Demo environment

This workshop pre-deploys `kuadrant-console-demo` with six mock APIs behind a shared Gateway (`kuadrant-demo.<domain>`):

* inventory-service
* payment-gateway
* order-management
* customer-loyalty
* shipping-tracker
* notification-hub

Each API has an `HTTPRoute`, `AuthPolicy` (API key via `X-API-Key`), `RateLimitPolicy`, `PlanPolicy` (free / basic / pro), and an `APIProduct` with OpenAPI docs.

== Create and use an API key

. Open *API Keys* → *Create API Key*.
. Select product `kuadrant-console-demo/inventory-service`, plan `free` (or `pro` for higher limits).
. Enter requester user id + email → *Create*.
. If the product is not auto-approved, use *Approve* on the row (label-based phase used by the console).
. Click *Reveal Key*, copy the value.
. Open the product *Definition* / Swagger UI and call the gateway with `X-API-Key` (or `Authorization: Bearer <key>` — mapped by the demo EnvoyFilter).

IMPORTANT: Plan *free* is intentionally tight (for example ~10 req/min, ~100/day). Hitting *429 Too Many Requests* means Limitador is working. Restart Limitador to flush counters in a demo: `oc rollout restart deployment/limitador-limitador -n kuadrant-system`.

== Observability

The plugin deep-links into Grafana dashboards provisioned by the observability chart:

* RHCL Traffic Overview
* RHCL Consumer Dashboard
* RHCL Cost & AI Dashboard
* RHCL Authorino metrics
* RHCL Limitador metrics

Mesh traffic is generated by `mesh-traffic-generator` so dashboards are populated on a fresh cluster.

== Helm deployment

The plugin is installed as `connectivityLink.helmApps` entry `custom-rhcl-console` in `examples/helm/values.yaml` (namespace *must* remain `custom-rhcl-console`).

Docs: https://maximilianopizarro.github.io/custom-rhcl-console/
