== 3scale Admin Portal

[cols="1,3",options="header"]
|===
| Field | Value

| *Admin Portal URL*
| https://3scale-admin.{cluster_domain}

| *Admin User*
| `admin` (default from `system-seed` secret)

| *Admin Password*
| Retrieve from the cluster — see command below

| *Admin Access Token*
| Retrieve from the cluster — see command below
|===

Retrieve the 3scale admin credentials from the Showroom terminal (or any `oc` session):

[source,bash]
----
# Admin password
oc get secret system-seed -n 3scale-system \
  -o jsonpath='{.data.ADMIN_PASSWORD}' | base64 -d && echo

# Admin access token (used by Migration Toolkit, APIShift, and API calls)
oc get secret system-seed -n 3scale-system \
  -o jsonpath='{.data.ADMIN_ACCESS_TOKEN}' | base64 -d && echo
----

TIP: The access token is what you paste into the *Migration Toolkit* and *APIShift* connection forms. Copy it once and reuse it throughout the workshop.

== All credentials at once

For a complete dump of all URLs and passwords, run from the Showroom terminal:

[source,bash]
----
cd /tmp
git clone https://github.com/Everything-is-Code/from-3scale-to-connectivity-link.git repo 2>/dev/null || true
bash repo/scripts/get-credentials.sh
----

This script prints every console URL, user, password, and token in the environment.
